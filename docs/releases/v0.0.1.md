0.0.1 是首个版本：不依赖 JDT LS 的轻量 Java 跳转，按插件契约 v0 编写。

功能：
- 跳转到定义：类型、方法、构造器、字段、枚举常量、局部变量、参数、类型参数、注解及其属性；按导入、同包、通配导入、嵌套、继承链和参数个数解析，支持调用链。
- Lombok：访问器跳到字段，`@Builder`、`@Slf4j` 和构造器注解生成的成员跳到注解。
- 跳进本机 JDK 的 `src.zip`，并能在 JDK 源码里继续跳；JDK 源码以只读副本打开，放在插件状态目录里。
- 查找引用：只列出能跳回该声明的出现。
- 文档结构（大纲）。
- 打开的文件按编辑器里未保存的内容索引。

平台：macOS（Apple Silicon、Intel）、Windows（x64、ARM64），每个平台一个 ZIP。

权限：`languageServer.launch`。

限制：不读依赖库（Spring、MyBatis、Lombok、Swagger 等的声明找不到）；没有 lambda 参数和泛型替换的类型推断；不要与 Java Support（JDT LS）同时启用。

兼容性：
- 只能装进新版 Lithe 桌面端（`desktop-v*` 预发布），旧版 macOS Lithe 无法安装。
- 本版本是预发布，Lithe Store 的自动追踪会跳过它。
