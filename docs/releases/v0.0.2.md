0.0.2 让 Eclipse 的老 Web 项目能跳进 Servlet、JSP 和 JUnit。

新增：
- 解析 `.classpath` 里的 Eclipse 容器（`kind="con"`）：服务器运行时容器（Tomcat、Jetty、WildFly、GlassFish/Payara、TomEE）
  换成本机装的服务器 `lib` 里的 `servlet-api.jar`、`jsp-api.jar`、`el-api.jar`，没装服务器就取本地 Maven 仓库里包名对得上的最新
  Servlet API 和 JSP API；按运行时版本区分 `javax.servlet` 和 `jakarta.servlet`（Tomcat 10+ 等用 `jakarta`）。
  `JUNIT_CONTAINER/3`、`/4`、`/5` 取本地仓库里对应大版本的最新 JUnit。项目自己带了 Servlet 或 JUnit 的 jar 时不再补。
- 没有 `pom.xml`、Gradle 构建文件，但有 `WEB-INF/web.xml` 的 Web 项目（MyEclipse、NetBeans、直接部署到 Tomcat 的项目）同样补上 Servlet/JSP API。
- 不联网下载，本机都没有就跳过；这些 jar 只读，不修改。

实测：Eclipse 动态 Web 项目 javaee-blog（Servlet + JSP，Tomcat 7 运行时容器，没有 pom）1500 个随机位置能跳转的比例从 91.7% 提到 100%，
`HttpServletRequest`、`getParameter`、`@WebServlet`、`@Test` 都跳到 Servlet API 和 JUnit 的源码；跳转 p50 0.08 ms，内存 17 MiB。
OpenCms（Gradle）为 94.1%，与 0.0.1 相同。

平台：macOS（Apple Silicon、Intel）、Windows（x64、ARM64），每个平台一个 ZIP。

权限：`languageServer.launch`。

限制：`.jsp` 文件里还不能跳转；Gradle 项目的依赖库还读不了；不要与 Java Support（JDT LS）同时启用。
