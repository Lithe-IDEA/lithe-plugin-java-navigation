0.0.3 改名为 Java Support Lite，作为 Java Support 的轻量版。功能和插件 ID（`io.github.lithe-idea.java-navigation`）不变，已安装的用户照常收到更新。

变更：
- 显示名称从 Java Navigation 改为 Java Support Lite；依赖库签名存根的首行注释同步改名。
- 与 Java Support 二选一：两者都为 Java 提供语言服务器，Lithe 同一时间只让一个已启用的插件服务一门语言，启用或安装其中一个会自动停用另一个并提示（需要包含 Lithe-core-rust#39 的桌面端）。
- Lithe Store 条目使用新图标（空心咖啡杯加闪电，改自 JetBrains IntelliJ Platform 的 Apache-2.0 图标，见仓库 `assets/NOTICE.txt`）。
