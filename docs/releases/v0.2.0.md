# Java Support Lite 0.2.0

## 中文

- 新增接口、父类、方法与实现类/子类之间的双向跳转：语言服务器实现 `textDocument/implementation`、`javaNavigation/superDeclarations` 与 `javaNavigation/markers`，支持双向查找与反向子类型关系解析。
- 通过同二进制 `--backend` 轻量后端向编辑器行号栏提供语义导航图标：绿色 `I↓` / `I↑`（接口实现）与蓝色 `O↓` / `O↑`（继承重写），并按宿主能力在旧版宿主上自动回退为通用导航图标；需要 Lithe 桌面端 0.8.17 或更高版本以获得完整交互体验。

---

## English

- Add bidirectional navigation between interfaces, superclasses, methods, and their implementations/subclasses: implement `textDocument/implementation`, `javaNavigation/superDeclarations`, and `javaNavigation/markers` with reverse subtype graph resolution.
- Provide IDEA-style editor gutter icons (`I↓` / `I↑` in green for interface implementations and `O↓` / `O↑` in blue for inheritance overrides) via the single-binary `--backend` mode, falling back to generic navigation icons on older hosts; Lithe Desktop 0.8.17 or later is recommended for full gutter icon support.
