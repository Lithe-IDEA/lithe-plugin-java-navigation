# Java Support Lite 0.2.1

## 中文

- 修复 `0.2.0` 插件清单声明 `editor.actions` 权限时缺少必需的 `documents.read` 权限，导致桌面端下载后在清单校验阶段安装失败的问题。
- 识别 Ant 类路径中 `lib` 目录之外的依赖 JAR。

---

## English

- Fix `0.2.0` manifest validation failure on install by adding the required `documents.read` permission alongside `editor.actions`.
- Index workspace dependency JARs declared on Ant paths outside `lib/` directories.
